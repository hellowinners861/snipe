# SNIPE

**一発に、静けさを。** 距離を測り、風を読み、スコープの向こうの一点へ。

近距離の静止標的から始め、移動標的、遠距離、高低差、変化する風、制限時間を順番に攻略する。弾丸は重力・空気抵抗・風のある3D空間を飛び、ライフル・弾薬・スコープの選択と操作が結果に反映される。

## 実装内容

- 全12ミッションと、条件を変えられる自由練習。
- Ranger / Sentinel / Kestrel / Atlasの4ライフル。ボルトアクションとセミオートを区別。
- 標準・精密・低抵抗・低速・リアクティブ用の5弾薬特性。互換性と解放条件あり。
- 3種のスコープ。倍率、上下・左右、mrad/MOA表示、FFP/SFP目盛り、傾き、ピント・眼位置の近似。
- 重力・空気抵抗・3Dの風・高低差・移動標的。1/240秒固定更新、RK4積分、連続衝突判定。
- オリジナルGLB 12モデル、銃別の作動・反動、BGM、発射・装填・遅延着弾音。
- 結果と着弾図、3方向の弾道リプレイ、無風・重力なしとの比較。
- PCと横画面タッチ操作。設定・進行・自己ベストをブラウザに保存。

構成はTypeScript + Vite + Babylon.js、音声はWeb Audio。モデル・音源は同梱され、外部アセット配信やアカウント登録は不要です。アセット一式は約3.2MBです。

物理原理と光学機能は一次資料を参照する。ゲーム内の銃名・弾薬名・性能調整値は独自設定とし、実在製品の完全再現や実射性能の保証は行わない。調査根拠と再現範囲は技術設計書に記載する。

## 起動

Node.js 24を使用します。

```bash
npm ci
npm run dev
```

表示された開発用URLの **`/snipe/`** を開いてください。WebGL対応ブラウザが必要です。スマホ・タブレットは横向きで使用します。初回のボタン操作で音声を有効にします。

```bash
npm test
npm run assets:check
npm run build
npm run preview
```

`npm test` は物理、衝突、装填、採点、全ミッションの達成可能性、画面遷移を検証します。DOMテストでは描画と音声を差し替えるため、実機の映像・音響の検証とは別です。

`npm run build` の `dist/` が配信用ファイルです。現在の基準パスは `/snipe/`。ルート配信へ変更する場合は `vite.config.ts` の `base` を合わせてください。

## 操作

| 操作 | PC | タッチ |
| --- | --- | --- |
| 狙いを動かす | 射場クリックで視点固定後、マウス | 射場をドラッグ |
| 発射 | 左クリック / Space | FIRE |
| スコープ | 右クリック / V | スコープボタン |
| 倍率 | ホイール / ＋− | 倍率の＋− |
| 息止め | Shift | 息止めボタン |
| ボルト・装填 | R | 装填ボタン |
| 上下・左右調整 | 矢印キー / 調整パネル | 調整パネル |
| 測距 | F | 測距ボタン |
| 銃の傾き | Q / E、Cで水平 | 上級調整パネル |
| 一時停止 | Esc | 一時停止ボタン |

アシストでも弾道は同じです。弾を標的に吸着させる処理はありません。入門・練習の任意の予測表示は、現在の観測風を一定と仮定し、未来の風や標的移動を先読みしません。

## 検証と素材

[実装・検証記録](docs/IMPLEMENTATION_STATUS.md)に、実装範囲、初版設計との差、検証結果、制約を記載しています。[素材の権利表記](THIRD_PARTY_NOTICES.md)も参照してください。

検証環境のクラウドブラウザではWebGLを初期化できなかったため、GPUでの実描画、実機の視認性・タッチ感度・fps、音の聴感は未確認です。数理・状態・DOM導線・モデル構造・音声データ・本番ビルドの検証とは分けて記録しています。

## GitHub Pages（任意の公開）

この実装には自動公開を含めていません。公開する場合は、リポジトリの **Settings → Pages → Source: GitHub Actions** を選び、Actionsの **Deploy to GitHub Pages** を手動実行します。CIの **Validate game** はPRとmain更新時に検証し、`snipe-static-build` に配信用ファイルを保存します。

## オリジナル素材の再生成

```bash
npm run assets:generate
npm run assets:check
```

Python標準ライブラリのみを使用します。生成スクリプト、アンカー、サイズ、ハッシュ、利用条件は `scripts/` と `public/assets/manifest.json` にあります。
