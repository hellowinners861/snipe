# SNIPE

スコープ越しに距離・風・動きを観察し、一発を決める、一人称3Dターゲットシューティングゲーム。

近距離の静止標的から始め、移動標的、遠距離、高低差、変化する風、制限時間を順番に攻略する。弾丸は重力・空気抵抗・風のある3D空間を飛び、ライフル・弾薬・スコープの選択と操作が結果に反映される。

## 現在の状態

2026-11-04時点では設計段階。開始時のリポジトリは空で、既存コード・依存関係・アセットはなかった。本変更では設計書のみを追加しており、ゲーム本体・3Dモデル・音源・公開サイトはまだ存在しない。

採用方針は TypeScript + Vite + Babylon.js、PCブラウザとスマートフォン・タブレットの横画面。最初の実装単位は「1射場・2ライフル・2弾薬・6ミッション」のMVPとする。

物理原理と光学機能は一次資料を参照する。ゲーム内の銃名・弾薬名・性能調整値は独自設定とし、実在製品の完全再現や実射性能の保証は行わない。調査根拠と再現範囲は技術設計書に記載する。
