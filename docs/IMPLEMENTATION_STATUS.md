# 実装・検証記録

記録日: 2026-11-04 / アプリ版: 1.0.0

## 実装した範囲

設計書の12ミッション、4ライフル、5種類の弾薬特性、3スコープ、4つの射場の環境、自由練習を実装した。選択→装備→射撃→結果→再挑戦／次ミッションの導線を持つ。進行に応じた装備解放、プリセット・入力方式・予測補助別の自己ベストを記録する。

| 項目 | 実装 |
| --- | --- |
| 弾道 | 1/240秒固定、RK4、相対空気速度、独自Cd曲線、温度・気圧の乾燥空気近似 |
| 環境 | 無風／一定風／連続的に変化する3D風場。旗と風観測は同じ場を参照 |
| 高低差 | 世界座標と一定重力。射座・標的の高さをミッションで指定 |
| 衝突 | 区間と標的平面・地面・箱。移動標的は接触時刻の位置で評価 |
| 照準 | 光軸と銃口を分離。モデル台帳の銃口・眼位置から物理用オフセットを取得 |
| スコープ | 視野角による倍率、FFP/SFP、上下・左右、単位換算、銃の傾き |
| 視差・ピント | 眼位置と距離差の近似。ピント不一致は画面のぼかし。レンズ光線追跡なし |
| 装填 | 薬室／マガジン／予備弾の分離。手動ボルト、自動ボルト、セミオート |
| モデル | 独自GLB 12種。ライフル4、スコープ3、標的4、風旗1 |
| アニメーション | 銃・カメラの反動、ボルトとマガジンの移動、旗と標的の反応を実行時に生成 |
| 音 | オリジナルWAV 12種、音声バス、風ノイズ、距離減衰・定位・到達遅延 |
| 記録 | 着弾図、記録済み軌跡、発射時速度、3視点と比較再計算 |
| 保存 | 検証付きlocalStorage、IndexedDBのリプレイ上限20件／20MB |
| 配布 | Viteの静的ビルド、PR/mainのCI、任意の手動Pages配信ワークフロー |

## 初版設計からの実装上の選択

- 音声はWeb Audio APIへ直接実装した。音量バス・位置に応じた定位・音源デコードを一か所で扱い、旧Babylon AudioEngineは使用していない。
- スコープ描画は全画質で単一カメラ＋円形マスクを採用した。二重描画を避けても、倍率とレティクルの角度関係は維持する。
- 視度はレティクルの描画の明瞭さを優先し、独立した操作にしていない。ジャイロ、ゲームパッド、キー割り当ての変更は未実装。PCの既定キー、保持／切替、反転、感度、左右タッチ配置を設定できる。
- 4射場は同じ軽量な景観生成器を使い、植生・岩・照明・霧・大気・標的配置で描き分ける。写真測量素材は使っていない。
- コリジョンは標的・地面・明示した壁と台座を対象にする。遠景の装飾は判定を持たない。貫通・跳弾・6自由度弾道は対象外。
- 弾道比較は保存した発射時速度と同じ環境時刻を用いる。移動標的への新しい得点は計算せず、学習用の差分として表示する。
- リプレイ保存は履歴の容量管理に使用する。現在のUIから再生できるのは直近の結果で、過去保存リプレイの一覧画面は未実装。
- BGMは16秒のオリジナルアンビエントループと成功フレーズ。場面別の複数楽曲や残時間による音楽のレイヤー追加は未実装。

## 実行した検証

`npm test`、`npm run assets:check`、`npm run build` を使用する。テストの実行結果と本番ビルドはCIにも保存される。

- 無抵抗の解析解との比較、抵抗による散逸、左右風の対称性、900mでの刻み半分との収束、基準角。
- 薄い標的、動く標的、手前の壁、平行区間の連続衝突。
- 30/60/120/144fpsでの再現性、中断時の停止、倍率による弾道の独立。
- 薬室・マガジン・予備弾、手動ボルト、装填中の状態、弾数の保存。
- 締切ちょうど／直後の着弾、0発での得点の有限性。
- 12ミッション×3プリセットを、テスト専用の照準計算で達成でき、金評価が可能であること。これは理想的な入力による計算上の確認であり、人による難度調整とは異なる。
- DOMテストで自由練習→装備互換→手動射撃・装填→設定保存→結果→リプレイの導線。描画と音声はテスト用実装へ差し替える。
- 24アセット（GLB 12、WAV 12）のバッファ範囲・法線・アンカー・ハッシュ・音声ヘッダー・非無音・非クリッピング・ループ端点。

## ブラウザ・実機の検証限界

検証用Chromeでプレビューを開いたが、WebGLコンテキストを作成できず `WebGL not supported` となった。ホスト名の設定は修正済みで、アプリ自体への到達は確認した。GPUによる3D描画、音の聴感、実機の操作性・fps・発熱については確認済みとは扱わない。

次の項目はWebGLが有効なPC／iPhone・iPad／Androidで確認する必要がある。

1. 4ライフルの向き、スコープ交換、手と銃の接触、光源、標的の立体感。
2. 高倍率での標的・レティクルの視認性と、FFP/SFPの角度目盛り。
3. タッチの同時操作、セーフエリア、スコープ保持、ピント、画面回転と自動停止。
4. 近い発射音と遅れて届く遠い標的音、アプリ切替後の音声復帰。
5. 10分プレイ、複数ミッションの再読込、標準／軽量画質のfps・メモリ。
6. 人の入力での各ミッション達成、金評価と制限時間のバランス。

実機測定をしていないため、設計書のfps・描画コール予算を達成済みとは表記しない。
