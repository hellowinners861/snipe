## 1. 企画の核

**「観察する → 条件を読む → 構えて調整する → 撃つ → 着弾を確かめる」という一発の体験を楽しむ3Dゲーム。**

最初は大きな的に当たる気持ちよさを、後半は風・距離・高低差・移動を読み切った達成感を中心にする。連射数や派手な爆発だけで気持ちよさを作らず、スコープ越しの静けさ、引き金の反応、反動、遅れて響く標的の音を一つの流れにする。

| 項目 | 決定 |
| --- | --- |
| ジャンル | 一人称・ミッション制・3D精密射撃 |
| 主な標的 | 紙、金属ゴング、可動プレート、陶製ディスク、機械式標的 |
| プレイ時間 | 1ミッション約2〜5分。練習場は時間無制限 |
| 対応 | PCブラウザ、スマートフォン・タブレットの横画面 |
| 操作言語 | 日本語を先行。表示文は後から翻訳できる構造 |
| 雰囲気 | 静かで写実的な屋外射場。器具は使い込まれた競技用品の質感 |
| 進行 | 達成で次ミッションと選択肢を解放。装備を単純な上位互換にしない |
| 料金・通信 | 初版はログイン・課金なしのシングルプレイ。サーバー必須機能なし |
| 移動範囲 | MVPは固定射座。完成版は指定された射座間の移動のみ |

人物との戦闘、敵AI、オープンワールド、銃器整備、経済システムは初版に含めない。遠くの的を狙う体験へ開発を集中する。

### 1.1 大切にする4原則

1. **結果に理由がある。** 外れた位置と飛翔を見直せる。ランダムな強制ミスを入れない。
2. **物理は共通、助け方を変える。** 入門でも重力を消さず、風のない環境や大きな標的、観察補助で易しくする。
3. **実物らしい操作を段階的に学ぶ。** 倍率、上下調整、左右調整、姿勢、視差の順に導入する。
4. **装備に用途がある。** 最も高威力のライフルだけで全課題が最適解にならない。

## 3. ゲームの流れと画面

### 3.1 1ミッションの流れ

1. **ブリーフィング:** 達成条件、標的、距離帯、高低差、天候、弾数、制限時間を確認する。
2. **装備:** ライフル・対応弾薬・スコープ・支えを選ぶ。入門では推奨装備が初期選択される。
3. **射座:** 周囲を見る。標的の動きと風の手がかりを確認する。
4. **照準:** スコープを覗き、倍率・調整ダイヤル・姿勢・呼吸を操作する。
5. **発射:** 発射時の銃口位置・銃身方向・装備・環境が弾道に反映される。
6. **観察:** 的の反応、砂煙、弾痕を確認し、必要なら次の一発を調整する。
7. **結果:** 達成、得点、命中位置、消費弾、射撃ごとのリプレイを見る。

制限時間は「開始」後、射場の読み込みと入力準備が終わってから進む。装備画面や初回説明で減らさない。端末のバックグラウンド移行では自動停止する。

### 3.2 画面一覧

| 画面 | 内容 |
| --- | --- |
| タイトル | プレイ、練習、設定。開始操作で音声を有効にする |
| ミッション選択 | マップの雰囲気、習得項目、達成状況、解放条件 |
| ブリーフィング | 目標、持ち込み条件、難度プリセット、推奨装備 |
| 装備 | 3Dライフルを回転表示。対応弾、倍率、反動・重さ・扱いやすさを比較 |
| プレイ | 3D射場、ライフル、残弾、時間、必要最小限のミッション情報 |
| スコープ | レティクル、倍率、調整値、必要に応じ距離・傾き・風観測 |
| 一時停止 | 再開、やり直し、操作、音量、画質、終了 |
| 結果・リプレイ | 的上の着弾図、弾道、得点内訳、次ミッション、再挑戦 |
| 練習場 | 環境・標的・装備を選び、同条件で繰り返し試せる |

### 3.3 HUDの情報設計

- 常時表示: 残弾、目標の進捗、制限時間がある場合の残り時間。
- スコープ内: レティクルと必要な目盛り。補助情報は周縁に置き、標的へ重ねない。
- 調整パネル: 「上下」「左右」を先に表示し、`Elevation` / `Windage` を補助表記する。
- 入門の風矢印: **風が吹いていく向き**。どこで観測した風かを添える。
- 距離表示: 視線距離を主表示。高低差ミッションでは高さの差を別表示する。
- 誤解を防ぐ文言: 「中心に狙った」「弾が中心に着く」を同義として説明しない。
- 倍率変更・ピント調整・射撃ボタンを同じ場所へ重ねない。
- 結果の説明は「この条件での比較シミュレーションでは風の影響が大きい」のように、解析の限界を表す。

## 4. 難度と学習

### 4.1 3つの操作プリセット

| 機能 | アシスト | スタンダード | シミュレーション |
| --- | --- | --- | --- |
| 重力・抵抗・設定された風 | 共通 | 共通 | 共通 |
| 照準の自動吸着 | なし | なし | なし |
| 距離 | 常時表示 | 測距操作時に表示 | ミッション支給機材の範囲 |
| 風 | 射座の観測値・矢印 | 観測器具と旗 | 旗・環境と支給機材 |
| 着弾予測 | 練習と入門のみ選択可 | なし | なし |
| ボルト操作 | 自動 | 自動／手動選択 | 手動が初期値 |
| 銃の傾き・視差 | 自動水平・自動センタリング | 水平計・自動センタリング | 手動の微調整も有効 |
| ピント | 自動 | 自動／手動選択 | 手動が初期値 |
| 結果の弾道表示 | あり | あり | ミッション終了後にあり |

予測表示はゲーム内の補助。現在取得できる風・標的状態を一定と仮定した予測とし、未来の突風や標的の進路を読み取らない。弾自体の向きや命中判定は変えない。

ミッションの配置難度と操作プリセットは別に管理する。アシストで最後まで遊べる。プリセット・補助使用・入力方式を記録し、同じ条件の自己ベストを比較する。

### 4.2 チュートリアル方針

一度に新しい概念は原則1つ。説明は短い1画面と、プレイ中の任意ヒントで行う。初回から専門用語を暗記させない。失敗が続いたら、再挑戦画面で「標的を大きくした練習」「着弾を見直す」を提示する。

入門では精密弾の散布を小さく設定し、操作ミスと弾薬固有のばらつきを区別できるようにする。攻略に必要な機能を教える前に制限時間を厳しくしない。

## 5. ライフルと照準の操作

### 5.1 「角度を変える」の内訳

| 操作 | 現象 | ゲームでの扱い |
| --- | --- | --- |
| 左右へ振る／上下に向ける | 銃全体の向きを変える | マウス・ドラッグで連続操作 |
| エレベーション | スコープの上下の角度設定 | ダイヤルをクリック単位で調整。弾へ力を加える処理にしない |
| ウィンデージ | スコープの左右の角度設定 | 上下とは独立したダイヤル |
| カント | 銃を銃身方向の軸まわりに傾ける | 水平計と銃モデルの傾きに反映 |
| ゼロ設定 | 基準となる銃身と照準の関係 | 銃・弾・照準器の組に保存したゲーム内基準設定 |
| 倍率 | 見える範囲と拡大率 | 倍率を上げるほど視野が狭く、揺れが見えやすい |
| サイドフォーカス／視差調整 | 標的像とレティクルの見え方 | ピントと眼位置によるずれを近似する |
| 接眼部の視度 | レティクルの見やすさ | 初回の視認性設定へ集約。毎回の作業にはしない |

スコープ調整が銃身そのものを機械的に曲げるような演出はしない。プレイヤーが再び標的へレティクルを合わせたとき、基準設定とダイヤル設定に応じた銃身方向になる。銃口・光軸・視点は別の位置として保持する。[R3][R4]

### 5.2 スコープ

| ID / 名称 | 倍率の初期案 | 焦点面 | 役割 | 導入 |
| --- | --- | --- | --- | --- |
| `scope_field` / Field | 3〜9倍 | SFP | 広い視野で基礎を覚える | M01 |
| `scope_precision` / Precision | 4〜16倍 | FFP | 移動標的と距離変化を扱う | M03 |
| `scope_survey` / Survey | 6〜24倍 | FFP | 小さな遠距離標的 | M07 |

数値はゲーム用初期案。SFPは画面上のレティクルの大きさが一定で、目盛りの角度としての意味は規定倍率に依存する。FFPは標的像とレティクルが一緒に拡大し、角度目盛りの意味が保たれる。[R5]

- MVPの操作単位はmradに統一。MOA表示は完成版で追加し、内部の角度を換算するだけにする。
- 初期スコープは1クリック0.1 mradという**ゲーム設定**を採用。可動上限はスコープ定義に持つ。
- ダイヤルの回転数・現在値・基準へ戻すボタンを表示。数字だけ増やして上限を無視しない。
- 調整前後で銃の狙いを自動的に標的へ吸着させない。
- 初版では完全な光学シミュレーションを行わず、視野、目盛り、ピント、眼位置、周辺の暗転を選別して再現する。
- 低画質でもレティクルと標的の角度関係、物理、判定は同じにする。

### 5.3 姿勢・呼吸・反動

| 要素 | 仕様 |
| --- | --- |
| 姿勢 | MVPは伏せ姿勢＋支え。完成版で座射／膝射と射座の支えを追加 |
| 呼吸の揺れ | 周期成分＋滑らかな微小揺れ。突然照準が跳ぶランダム入力は禁止 |
| 息止め | 短時間だけ揺れを抑える。残量と回復状態を表示。連打で無限安定しない |
| 発射時点 | 引き金が成立した瞬間の姿勢を確定して弾を生成 |
| 反動 | 確定後に銃・カメラ・手のアニメーションへ適用。飛翔中の弾は動かさない |
| ボルト | 発射後に排莢・次弾装填。手動設定では操作が終わるまで次弾を撃てない |
| セミオート | 1回の入力につき1発。押しっぱなしで自動連射しない |
| 装填 | マガジンと薬室を別に管理。弾が二重消費・複製されない |

実物の細かな整備や故障対応は初版では扱わない。ストックやチークレストの外観差は3Dモデルに反映し、実物の調整工程をプレイの必須操作にはしない。[R6][R7]

### 5.4 操作割り当て

| 操作 | PC初期割り当て | タッチ初期割り当て |
| --- | --- | --- |
| 視点・狙い | マウス移動 | 主領域をドラッグ |
| スコープ | 右クリック、押下／切替を設定可能 | 大きなスコープボタン |
| 発射 | 左クリック | 独立した発射ボタン |
| 倍率 | ホイール | ＋／−、倍率スライダー |
| 息止め | Shift | 保持ボタン、切替モードも選択可 |
| ボルト／装填 | Rで必要な操作。長押しでマガジン交換 | 状態に応じ「装填」「ボルト」を表示 |
| 上下・左右ダイヤル | 調整パネルで選択し＋／− | 調整パネルで＋／−、長押し連続 |
| 傾き | Q / E | 上級操作パネル |
| 測距 | F | 測距ボタン |
| 一時停止 | Esc | 一時停止ボタン |

キー変更、左右配置反転、照準反転、倍率別感度、操作の保持／切替を用意する。スマホのジャイロは任意の補助で、使わなくてもクリアできる。指を離す動作で誤発射しない。ゲーム領域のみブラウザのスクロールとダブルタップ拡大を抑制する。

## 6. ライフル4種類

銃名は架空。小型のボルトアクション、調整式ストックを持つ精密ライフルなど実在の構成を参考にし、形状・重量感・作動方式を描き分ける。実在商品のロゴや性能を無断で保証する表現は使わない。[R6][R7]

| ID / 名称 | 方式・対応弾薬系統 | 得意な課題 | 代わりに難しい点 | 解放 |
| --- | --- | --- | --- | --- |
| `ranger` / Ranger | 軽量ボルト、L系統 | 近中距離の基礎。小さい反動で着弾を観察しやすい | 長距離では飛翔時間と抵抗の影響が目立つ | 初期 |
| `sentinel` / Sentinel | 精密ボルト、M系統 | 中遠距離、安定した一発、ミッションの標準装備 | ボルト操作が必要。軽量銃より切り返しが遅い | M02後 |
| `kestrel` / Kestrel | セミオート、M系統 | 複数の動く標的、短い射撃機会 | 連続発射の揺れ・反動回復を管理する | M06後 |
| `atlas` / Atlas | 重量級ボルト、H系統 | 遠距離、大きな反応が必要な機械標的 | 構え直しが遅い、反動が大きい、持ち込み弾数が少ない | M08後 |

「セミオートだから必ず不正確」「重い弾なら必ず風に強い」という分類にはしない。散布・弾道・反動は各プロファイルの組み合わせから決める。画面の比較バーは正規化したゲーム内評価であり、物理計算の入力に使わない。

各ライフルに専用の3Dモデル、手との接触位置、銃口位置、スコープ位置、装填アニメーション、発射音セットを用意する。色違いだけで別種類としない。

## 7. 弾薬と標的への反応

### 7.1 弾薬の選択

弾薬は「互換系統L/M/H」と「性質」で管理する。同じ性質でも系統ごとに別アイテム。対応しない銃へ装填できない。ミッション中の持ち込み上限は弾数で管理し、課金や恒久的な購入資金には結びつけない。

| 性質 / ID | 弾道・ばらつき | 標的との関係 | 制約と用途 |
| --- | --- | --- | --- |
| 標準 / `standard` | 基準となる設定 | 通常の紙・ゴング | 十分な持ち込み数。多くの課題に使用可 |
| 精密 / `match` | 速度・発射方向のばらつきを小さくする | 小さい採点円 | 重力や風はそのまま。使用可能弾数が少なめ |
| 低抵抗 / `low_drag` | 空気抵抗曲線を変え速度保持を重視 | 遠距離の小標的 | 互換銃とミッションが限定。風の影響が消えるわけではない |
| 低速 / `low_velocity` | 発射時の速度を下げる | 音と飛翔時間を比較する課題 | 遅い到達、大きな落下。独立した基準設定が必要 |
| リアクティブ用 / `reactive` | プロファイルに従う通常の飛翔 | 機械式標的の反応を強めるゲーム用設定 | 精密採点・弾数とのトレードオフ。実材貫通性能を表さない |

完成版の互換表は次で固定し、装備画面とデータ検証の両方で制限する。

| 弾薬の性質 | L / Ranger | M / Sentinel・Kestrel | H / Atlas |
| --- | --- | --- | --- |
| 標準 | 可 | 可 | 可 |
| 精密 | 可 | 可 | 可 |
| 低抵抗 | 不可 | 可 | 可 |
| 低速 | 可 | 可 | 不可 |
| リアクティブ用 | 不可 | 可 | 可 |

MVPはL・M系統それぞれの標準／精密のみ。低抵抗・低速・リアクティブ用は完成版で追加する。

### 7.2 「威力」の扱い

- 内部では着弾時の運動エネルギーと運動量を保持する。ただし両者を同じ数値として扱わない。
- 紙の採点は命中位置を優先し、強い弾ほど点数が増える設計にしない。
- ゴングは命中で得点。揺れと音の強さは着弾条件を基に上限付きで演出する。
- 陶製ディスクは破砕表現、機械式標的はゲーム用の反応閾値を使う。
- 反応閾値を満たさない場合も命中自体は記録し、「命中・作動不足」と説明する。
- 装備画面でクリア不能な組み合わせを事前に示す。必須弾薬はそのミッションで無償支給する。
- 壁の材質別貫通や跳弾は初版の対象外。弾は最初の衝突で終了し、その位置に適切なエフェクトを出す。

## 8. 弾道と環境をプレイヤーにどう感じさせるか

| 条件 | 体験・見え方 |
| --- | --- |
| 距離 | 発射と着弾の間に時間がある。遠方では的の反応音がさらに遅れる |
| 重力 | 弾は直線を保たない。リプレイで弧を確認できる |
| 空気抵抗 | 遠くまで同じ速度では進まない。弾の性質によって変化する |
| 風 | 横風だけでなく方向を持つ3Dの空気の流れとして作用 |
| 風の空間差 | 射座の風速計だけでは遠方の条件を完全には知れない |
| 高低差 | 高い射座・低い射座の両方を使う。重力の向きは世界の下方向に固定 |
| 移動 | 発射時の標的位置へ自動命中しない。飛んでいる間も標的が進む |
| 気温・空気密度 | 完成版の環境プリセットに反映。独立した「難度倍率」では変えない |
| 姿勢・呼吸 | 発射時の銃の向きが変わる。弾が飛び始めてから補正しない |

風は旗、草、低い粉塵、環境音、観測機材で伝える。手がかりは物理と同じ風場を参照する。霧・雨・陽炎は主に視認性に作用し、物理への影響を説明せず追加しない。

練習場では風、標的速度、距離、サイズ、高低差、散布の有無を変えられる。変更した条件は画面に残し、リプレイにも記録する。

### 9.1 進行・失敗・再挑戦

- 基本達成で次へ進める。高評価を取らなければ装備不足で詰む構成にしない。
- 失敗条件: 必須標的未達で時間切れ、または残弾・薬室・飛翔中の弾がなく達成不能。
- 制限時刻までの**着弾**が達成対象。締切ちょうどは成功扱い。発射だけでは達成しない。
- 時間切れ後の弾はリプレイ用には追跡しても、達成には加算しない。
- 「同じ条件で再挑戦」は風と標的の乱数種を維持。「別条件で練習」は新しい種に変える。
- ヒント利用を責める表示や、失敗による装備没収は入れない。

### 9.2 採点

基本達成とスコアを分離する。ミッションごとに指定された得点対象の命中だけを集計し、撃破済み標的を何度も撃って稼げないようにする。

| 得点要素 | 比率 | 定義 |
| --- | --- | --- |
| 精度 | 70% | 必須命中ごとの採点域の平均。未達の枠は0点。中心1.0、内周0.8、外周0.5 |
| 弾の効率 | 20% | 達成した必須命中数 ÷ 発射数。0〜1に制限 |
| 時間 | 10% | `残り時間 / 制限時間`。無制限課題ではこの要素を除いて再正規化 |

1000点満点に換算。0発では弾の効率を0とする。メダルは全目標達成が共通条件で、700点未満なら銅、700点以上で銀、900点以上で金。金が到達可能かはミッションごとの最短時間・装填時間を含めて調整する。大型機械標的など精度を評価しない課題は、指定命中領域への命中を精度1.0として定義する。

## 10. 3Dビジュアルとアニメーション

### 10.1 見た目

現実的な大きさと材質を持つ、軽量な写実表現を目指す。金属、樹脂、塗装、木、布、砂利をPBR材質で区別する。遠くの標的には背景との明暗差を確保し、霧や草が常に重なって見えない配置を避ける。

世界は射座付近に細密さを集め、遠景は簡略化する。ただしスコープで覗いた標的・遮蔽物の形状は十分な精度を保つ。画質を下げても標的の判定サイズや遮蔽物の存在を変えない。

### 10.2 必須アセット

| 分類 | MVP | 完成版 |
| --- | --- | --- |
| ライフル | Ranger・SentinelのGLB 2種 | Kestrel・Atlas追加、計4種 |
| 一人称の手 | 共通リグ＋銃ごとのポーズ | 作動方式ごとの調整 |
| スコープ | Field・Precision | Survey追加 |
| 標的 | 紙、ゴング、レール式プレート | 陶製、機械式、複数の可動機構 |
| 射場 | 訓練場＋高台の射座 | 採石場、渓谷、山岳 |
| 小物 | 旗、砂袋、支え、机、標的スタンド、岩、草 | 観測器具、環境差分 |
| エフェクト | 銃口光、煙、排莢、砂煙、弾痕、ゴング揺れ | 破砕、陽炎、天候差分 |

銃の構え、スコープへの移行、発射、ボルト、マガジン交換、空撃ち、装備表示にはアニメーションを付ける。排莢位置、銃口、手の握り、スコープの覗き口をモデル内の名前付き位置で管理する。

単純な箱・円柱は開発中の仮素材としてのみ使い、MVP完成条件には正式な3Dモデルと材質を含める。2Dの銃画像を貼っただけの実装で完了にしない。

### 10.3 スコープ表現

- 標準画質: 拡大カメラで描いた円形のスコープ像＋3Dの鏡筒。外側の描画負荷を抑える。
- 低画質: 単一カメラの狭い視野＋円形マスクへ切り替え、二重描画を減らす。
- 銃の位置、眼位置、眼と鏡筒のずれに応じた周辺暗転を付ける。
- 背景を暗くしすぎず、タッチ端末でもレティクルを判読できる。
- 弾そのものを常時光る線にしない。弾道の可視化は練習補助・結果画面に集約する。
- 通常の射撃中に毎回スローモーションへ切り替えない。リプレイは任意再生。

## 11. BGM・効果音

### 11.1 音の構成

| 音 | 表現・実装方針 |
| --- | --- |
| タイトル・装備BGM | 静かなアンビエント。落ち着いて選べる曲 |
| 射撃中BGM | 低音量・少ない楽器。風や機関音を邪魔しない |
| 時間制限BGM | 残時間で控えめな層を追加。急な大音量は禁止 |
| 結果BGM | 短い成功フレーズ。失敗時も再挑戦を妨げない |
| 発射音 | ライフル別の近距離音・機関音・環境の反響を重ねる |
| 操作音 | ボルト、マガジン、ダイヤルのクリック、衣擦れ、支え |
| 呼吸音 | 息止めの状態を補助。不要なら独立して下げられる |
| 着弾音 | 金属、紙、土、岩、破砕を区別。距離減衰・到達遅延を付ける |
| 環境音 | 風、草、鳥、遠い機械音。方角・環境で変化 |
| UI音 | 決定、戻る、解放、残弾なし。耳障りな連続再生を制限 |

遠くの的はまず見た目が反応し、その場所から音が届くまで間を置く。耳元の発射音には遠方標的までの往復遅延を誤って付けない。ゲーム通知としての命中音と、物理的な標的音を別にし、シミュレーション設定では即時の通知音を初期OFFにする。[R10][R11]

### 11.2 音量・素材

- Master / BGM / 発射・機関 / 環境 / UIを別バスにする。ミュートと音量を保存。
- BGMは開始・停止のクリックノイズを防ぎ、シーン間でクロスフェードする。
- 同じ発射音の反復感を減らすため複数バリエーションを使う。物理結果の乱数とは分離する。
- 音量差を抑える設定を用意し、写実性を実音量の再現と混同しない。
- 無音でもクリアできる視覚表示を備える。
- MVPでも実際のBGM、録音または適切に合成した銃・機関・着弾音を入れる。単一のビープ音だけで完了にしない。
- 原曲または利用可能な素材を採用し、作者・出典・ライセンス・変更内容を台帳に残す。特定曲の無断流用は行わない。

## 12. リプレイと学び

発射直前の状態、実際の弾道、標的の動き、着弾位置を記録する。結果画面では射撃一覧から1発を選び、横・上・射手視点を切り替えられる。

- 的に当たった場合: 的のローカル座標に着弾点を表示。動く標的でも正しい場所に残す。
- 外れた場合: 最も近づいた時点と距離、地面などへの衝突点を表示する。
- 比較表示: 同じ入力で「無風」「重力なし」などを再計算するのは結果画面の学習用のみ。
- 比較した差分は複数要素の相互作用を含む。「原因を完全に分解した値」とは呼ばない。
- 自己ベスト、ミッション達成、操作設定は端末保存。リプレイは容量上限を設け古いものから削除。
- 初版でオンライン順位表や他プレイヤーの幽霊データは作らない。

### 13.1 最終チェック

- スコープを覗き、遠くの立体標的を狙う体験が中心にある。
- 重力・抵抗・風・高低差・標的移動が、それぞれ説明可能な結果になる。
- 銃と弾の違いが外観・音・反動・装填・飛翔・標的反応に現れる。
- 初心者が操作を学べ、上級操作も選択できる。
- PC・スマホでUIが重ならず、射撃や倍率変更が誤作動しない。
- BGMと効果音が入り、音なしでも重要な情報が得られる。
- 実装順・受入条件・出典が技術設計書と一致する。
